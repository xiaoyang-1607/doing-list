## Doing List v0.1.3

这是一次以数据可靠性、桌面安全和发布质量为重点的维护版本。

### 功能与可靠性

- 日记编辑支持自动保存，减少切换日期或页面时的内容丢失风险。
- 重复导入任务摘要时只替换自动生成区块，保留用户手写内容。
- 删除任务或移除图片时清理无引用附件，并限制附件数量与路径范围。
- 增加更严格的日期、任务、日记、AI 设置和 IPC 输入校验。

### 安全

- AI API Key 改用系统安全存储加密，渲染页面无法读取已保存的明文密钥。
- 非本机 AI 服务地址必须使用 HTTPS。
- 启用 Electron 渲染沙箱、上下文隔离与内容安全策略，并禁用 Node.js 集成。
- 升级 Electron、Vite、electron-vite、electron-builder 和 better-sqlite3，完整依赖审计为 0 个已知漏洞。

### 构建与发布

- CI 增加生产依赖审计、CodeQL、依赖变更审查和 Dependabot。
- GitHub Actions 固定到不可变提交 SHA。
- 发布前自动校验 tag、包版本和变更日志一致性。
- 干净构建 Windows 安装包，并在打包后的 Electron 中执行 SQLite 冒烟测试。
- Release 附带 `SHA256SUMS.txt`，便于验证下载文件完整性。

### 安装与升级

下载 `Doing-List-Setup-0.1.3.exe` 并运行即可覆盖升级。任务、日记和附件仍保存在 `%APPDATA%\doing-list`；升级前建议备份该目录。

当前安装包尚未进行代码签名，Windows 可能显示“未知发布者”。请只从本仓库 Release 页面下载，并核对 `SHA256SUMS.txt`。
