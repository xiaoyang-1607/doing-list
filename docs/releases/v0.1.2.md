## Doing List v0.1.2

### 新增与改进

- 支持同时按任务状态和分类筛选。
- 日记支持导出当前篇或全部内容为 Markdown。
- 导入任务摘要时使用明确边界，重复操作会替换自动生成部分，不影响用户后续手写内容。
- 修复早期版本的启动和打包问题。

### 下载

Windows 用户请下载 `Doing-List-Setup-0.1.2.exe`。当前安装包未进行代码签名，Windows 可能显示“未知发布者”；请仅从本仓库 Release 页面下载并核对校验值。

### 数据说明

任务、日记和附件保存在 `%APPDATA%\doing-list`。AI 功能为可选项，只有用户主动调用时才会把相关内容发送到所配置的服务商。
