## Doing List v0.1.4

这是一个修复任务摘录显示问题的维护版本。

### 安全

- 将间接依赖 `nanoid` 更新到 3.3.18，修复自定义生成器在长度为零时可能无限循环的问题。

### 修复

- 引入任务摘录后，日记正文编辑框不再显示 `<!-- doing-list:task-excerpt:start -->` 和 `<!-- doing-list:task-excerpt:end -->` 内部标记。
- 任务摘录现在显示在独立的只读区域，再次引入任务时会安全更新，不会覆盖手写正文。
- Markdown 导出和 AI 周/月回顾会自动移除内部定位标记。
- GitHub Release 不再上传 electron-builder 调试配置等非用户安装文件。

### 兼容性

- 已有日记中的任务摘录会自动识别，无需迁移数据库。
- 用户任务、日记和附件仍保存在 `%APPDATA%\doing-list`，覆盖安装不会删除现有数据。

### 安装与校验

下载 `Doing-List-Setup-0.1.4.exe` 并运行即可覆盖升级。Release 同时提供 `SHA256SUMS.txt`，可使用 PowerShell 验证安装包：

```powershell
Get-FileHash -Algorithm SHA256 .\Doing-List-Setup-0.1.4.exe
```

当前安装包尚未进行商业代码签名，Windows 可能显示“未知发布者”。请只从本仓库 Release 页面下载并核对 SHA-256 校验值。
