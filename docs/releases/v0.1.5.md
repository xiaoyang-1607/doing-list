## Doing List v0.1.5

这是一个修复日记任务摘录编辑体验的维护版本。

### 修复

- 引入的任务摘录重新自动显示在同一个“正文”编辑框中，不再与正文分成两个区域。
- 任务摘录可以像普通正文一样直接编辑。
- 再次引入任务时会原位更新已跟踪的摘录，并保留摘录前后的手写内容。
- 内部定位标记仍只用于数据存储，不会显示在正文、Markdown 导出或 AI 回顾中。

### 兼容性

- 自动兼容 v0.1.4 保存的日记，无需迁移数据库。
- 用户任务、日记和附件仍保存在 `%APPDATA%\doing-list`，覆盖安装不会删除现有数据。

### 安装与校验

下载 `Doing-List-Setup-0.1.5.exe` 并运行即可覆盖升级。Release 同时提供 `SHA256SUMS.txt`，可使用 PowerShell 验证安装包：

```powershell
Get-FileHash -Algorithm SHA256 .\Doing-List-Setup-0.1.5.exe
```

当前安装包尚未进行商业代码签名，Windows 可能显示“未知发布者”。请只从本仓库 Release 页面下载并核对 SHA-256 校验值。
